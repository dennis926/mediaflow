# NeedAi 内容分发系统 产品需求文档（PRD）

> 内部代号 MediaFlow。本文描述**当前已交付的真实能力**，不是规划稿。
> 每次版本迭代同步更新；版本历史见根目录 `CHANGELOG.md`。

## 1. 产品定位

面向公司内部（10 人以内）的**社交媒体内容分发与矩阵运营平台**：

> 一次创作 → AI 生成多平台版本 → 审核 → 排期 → 发布 → 回收数据。

所有业务表预留 `tenant_id` / `workspace_id`，配置全部可改（站点名、平台、字段、文案、价目），
目标是把程序交给别的公司时**改配置就能上线**，不需要改代码。

- 线上：<https://auto.liangyijianye.cn/>（PC）、`/h5/`（移动端）、`/api/`（后端）
- 界面品牌名来自设置项 `SITE_NAME`；版本号见侧边栏页脚

## 2. 目标用户与角色

| 角色 | 主要职责 |
| --- | --- |
| 内容运营（editor） | 创作内容、AI 生成多平台版本、排期发布、回收数据 |
| 审核人（reviewer） | 审批内容（不可审核自己提交的内容） |
| 管理员（admin） | 账号绑定、用户与工作区、AI 与平台配置、审计 |
| 所有者（owner） | 同管理员 + 工作区生命周期（归档/软删/永久清除） |
| 只读（viewer） | 仅查看 |

## 3. 功能模块（均已实现）

| 模块 | 能力 |
| --- | --- |
| 内容中心 | 内容 CRUD、版本历史与回滚、状态机（草稿/审核中/已通过/已驳回/已归档）、标签与平台版本 |
| AI 适配 | 多平台版本生成、标题优化、合规检查；品牌知识库检索注入；全部调用留痕（token/费用/档位） |
| 文案模板 | 模板 CRUD、套用计数、按平台/场景筛选 |
| 素材库 | 上传（本地磁盘）、签名链接访问、AI 生成标识写入元数据 |
| 知识库 | 分类管理、文档导入（PDF/Word/Excel/PPT/CSV/TXT/MD，含 OCR 开关）、检索匹配面板、引用计数 |
| 发布中心 | 发布任务（多平台）、Redis Stream 异步队列、失败重试、人工回填发布结果、排期日历周视图 |
| 内容审核 | 审核流、驳回需理由、快照内容版本（改后需重审）、审核人 IP/UA 留痕 |
| 数据中心 | 概览指标、趋势、内容排行、账号排行；三种数据来源（平台同步 / 插件回传 / 人工录入） |
| 账号管理 | 平台账号绑定（OAuth）、无凭据账号登记、解绑、Token 自动刷新 |
| 浏览器插件 | 小红书/视频号/知乎/头条/百家号内容填充 + 人工确认发布；任务拉取与数据回传 |
| 用户与工作区 | 用户 CRUD、角色分配、多工作区切换、成员管理 |
| 工作区生命周期 | 归档（可逆）→ 软删除（默认 30 天，可配 7-365）→ 永久清除（二次确认 + 独立备份 180 天） |
| 数据导出 | 工作区整包导出（5GB 上限、单并发、7 天保留、一次性签名链接 15 分钟） |
| AI 用量与计费 | 官方价计费、峰谷两档、官网价格自动抓取、按天/任务/模型统计、配额与用量记录 |
| 运行监控 | 7 项巡检（队列积压、磁盘、发布失败率、登录失败、跨工作区引用与孤儿行、AI 配额等），按平台/工作区区分口径 |
| 审计与合规 | 审计日志、AI 生成标识（显式 + 隐式）、合规词库、数据删除请求台账 |
| 系统设置 | 10 个分组约 100 项配置，密钥加密入库（AES-256-GCM），改动免重启生效 |

## 4. 平台发布能力矩阵

依据各平台**实际开放能力**核定（2026-09 实测），不是理想清单：

| 平台 | 发布方式 | 依据 |
| --- | --- | --- |
| 微信公众号 | **仅创作辅助 + 人工手动发布** | 《微信公众平台运营规范》3.27 禁止 AI/脚本/接口自动化发布；系统永不调用群发接口 |
| 抖音 | 官方发布 API（OAuth） | 开放平台提供视频发布接口；互动类接口已回收，**不做** |
| 百家号 | 官方发布 API | 开发者服务提供图文发布接口 |
| 小红书 | 插件填充 + 人工确认 | 开放平台已转型电商，无内容发布 API |
| 视频号 / 知乎 / 今日头条 | 插件填充 + 人工确认 | 无成熟官方发布 API |

> 所有平台都支持「人工回填」闭环：填平台链接 + 备注即标记为已发布，不依赖任何 API。

## 5. AI 计费口径

- **官方价**：国内供应商（DeepSeek）取官网人民币价，海外供应商按官方美元价 × 汇率；不加价、不打折。
- **峰谷两档**：按调用时刻判定（DeepSeek 口径：工作日 09:00-12:00、14:00-18:00 为高峰，其余含周末与法定节假日为空闲，空闲价为高峰价的一半）。
- **自动跟随调价**：定时抓取供应商官网价目表（默认 12 小时），也可手动触发；抓取失败保留上一份价格，不影响计费。
- 每次调用记录生效档位与单价，费用可追溯。详见 `docs/DESIGN-AI计费口径.md`。

## 6. 合规要求（法定）

- AI 生成内容必须带**显式标识**（正文末尾"（本文由 AI 辅助生成）"）与**隐式标识**（媒体元数据）。
- 发布前必须通过 `ai_content_flag_checked` 检查。
- 食品/保健类内容不得出现治疗、疗效等违禁表述；内置合规词库 + AI 复核双保险。
- 数据删除请求有台账与承诺时限；永久清除前必须完成独立备份。

## 7. 非目标（明确不做）

- 平台私信 / 评论自动互动（接口已回收，且违反平台规范）
- 微信公众号 API 自动群发（法规禁止）
- 未经人工确认的全自动发布

## 8. 技术约束

见 `AGENTS.md`（项目宪法）：TypeScript 严格模式、pnpm、统一响应体 `{ code, message, data }`、
业务表必须带 `tenant_id`/`workspace_id`/`created_at`/`updated_at`、Design Token 唯一来源、
H5 点击区域 ≥44px、注释用英文。
