# MediaFlow 产品需求文档（PRD）

> 状态：骨架占位。随各阶段开发逐步补全。

## 1. 产品定位

MediaFlow 是面向公司内部（10 人以内）的社交媒体内容分发与矩阵运营平台：一次创作，多平台适配，统一排期发布，回收数据。未来可能对外 SaaS 化（因此所有表预留 tenant_id / workspace_id）。

## 2. 目标用户

- 内容运营：创作内容、调用 AI 生成多平台版本、排期发布
- 审核人：审批内容与发布计划
- 管理员：管理账号绑定、角色权限、查看数据看板

## 3. 核心功能模块

| 模块 | 说明 | 实施阶段 |
| --- | --- | --- |
| 内容中心 | 内容 CRUD、版本管理、AI 多平台适配 | Prompt 4 |
| 发布中心 | 发布任务、队列、日历排期、失败重试 | Prompt 3 / 7 |
| 数据中心 | 指标概览、趋势、内容与账号排行 | Prompt 8 |
| 账号管理 | 平台账号绑定 / 解绑、Token 生命周期 | Prompt 8 |
| 审批中心 | 内容审批流、审批记录 | 后续阶段 |
| 浏览器插件 | 小红书 / 视频号 / 知乎 / 头条 / 百家号半自动填充 | Prompt 9 |
| 系统管理 | 用户、角色、审计日志 | 后续阶段 |

## 4. 平台发布能力矩阵（依据 AGENTS.md 第 4 节）

| 平台 | 发布方式 | 互动（私信/评论） |
| --- | --- | --- |
| 微信公众号 | 仅创作辅助 + 人工手动发布（禁止 API 群发） | 不提供 |
| 抖音 | 官方发布 API（OAuth） | 不提供（接口已回收） |
| 小红书 | 官方笔记发布 API，插件兜底 | 不提供 |
| 视频号 / 知乎 / 头条 / 百家号 | 浏览器插件填充 + 人工点击发布 | 不提供 |

## 5. 合规要求

- AI 生成内容必须带显式标识（正文末尾"（本文由 AI 辅助生成）"）与隐式标识（媒体元数据）
- 发布前必须通过 ai_content_flag_checked 检查
- 食品 / 保健类内容不得出现治疗、疗效等违禁表述

## 6. 非目标（当前版本不做）

- 平台私信 / 评论自动互动
- 公众号 API 自动群发
- 多租户计费与开放注册
