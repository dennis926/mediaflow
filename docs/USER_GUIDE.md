## 2. AI 费用怎么算（重要）

系统按**各供应商官网的官方价**计费，不加价、不打折。

### 2.1 分峰谷的供应商（如 DeepSeek）

DeepSeek 的官方价分两档：

| 时段 | 什么时候 | 相对价格 |
| --- | --- | --- |
| 高峰 | 工作日 09:00-12:00、14:00-18:00（北京时间，不含法定节假日） | 全价 |
| 空闲 | 其余全部时间（含夜间、周末、法定节假日） | **半价** |

系统按**每次调用发生的那一刻**自动取对应档位。也就是说：晚上和周末批量跑内容，费用是按半价算的。

### 2.2 价格从哪来

1. 系统会**定时读取供应商官网的价目表**并自动跟随官方调价（默认每 12 小时一次）；
2. 也可以到「AI 用量」页点「立即抓取官网价」马上刷新；
3. 抓取失败不会影响计费——继续用上一次抓到的价格，只是暂时不跟随调价。

目前系统会自动抓取 **8 家**官网价目表：DeepSeek、智谱 GLM、Kimi、Grok（xAI）、Claude、Gemini、通义千问、豆包（火山引擎）。

抓不到官网价的（**ChatGPT/OpenAI**：官网拦截我们的出口 IP；**MiniMax**：价格由网页脚本动态生成；**豆包**：官网人机校验），系统会用两层公开价目兜底，所以这几家在价目表里**有价格可用**，不会显示成空白：

1. **国内权威参考价（国家超算互联网）**：科技部指导的国家级算力平台，公开刊例价、人民币计价。国内供应商抓不到官网价时优先用它——人民币进人民币出，不经过汇率换算。
2. **聚合价目表（models.dev）**：覆盖最广（10 家），但只有美元价、且不区分峰谷，所以只在前一层也没有时才用。

页面上「抓取」区里这两层各有一张卡片，写明覆盖家数与抓取时间；点「立即抓取」会一起刷新。

聚合价目表只做兜底：它只有美元价、且不区分峰谷，因此**只要官网能抓到，就一定用官网价**（国内供应商的峰谷两档尤其如此）。想更准可以在「AI 用量」页用「改价」手工覆盖。

「AI 用量」页顶部会显示**当前处于高峰还是空闲时段**，价目表里每个模型也会显示 `官方 峰 ￥X / 谷 ￥Y（当前 ￥Z）`，一眼能看清现在按哪一档算。

价目表下方有一块「**官网价格抓取**」面板，逐家显示抓到多少个模型、上次成功时间与来源网址。若某家显示红色「**抓取失败**」，面板会写清原因（例如豆包被官网人机校验拦住），并标注**已连续失败多少次**；抓不到时**保留上一份价格**，不会中断计费。

### 2.3 官方调价了怎么办

正常情况下系统会自动跟上，无需操作。若要手工指定（例如走了代理、价格另有约定），到「AI 用量」页点该模型的「改价」，填入实际单价；点「恢复官方价」即可改回自动跟随。

## 3. 首次使用要做的三件事

### 3.1 配置 AI（系统设置 → AI 配置）

AI 配置是**独立模块**，三步就能配好，不用手填模型名：

1. 左侧「系统设置」→ 顶部点「AI 配置」卡片进入
2. **填凭据**：选供应商（默认 DeepSeek）→ 填 API Key（形如 `sk-...`）→ 接口地址留空用官方地址
3. **测试连接**：点「测试连接」。会真的发一次请求，成功会显示耗时和模型回复；失败会显示具体原因（Key 错、地址错、余额不足等）
4. **获取模型**：测试通过后「获取模型」才可点。点完直接列出该 Key 能用的全部模型
5. **选择默认模型**：从列表里勾一个（或手动填模型标识），点「保存并设为默认」

保存后**立即生效，不需要重启服务**。以后换供应商，重复第 2–5 步即可。

> - 密钥加密后存入数据库，界面只显示前后几位；密钥框里显示的是打码值，原样保存不会覆盖原有密钥。
> - 想先不花钱试流程，把供应商选成「离线占位」，此时生成的是带「离线占位」字样的示例文本。
> - 有些供应商协议没有「获取模型」接口（如 Anthropic 原生协议），点它会明确提示，此时手动填模型标识即可。

#### 用第三方中转站（不是官方 API）

「AI 配置」卡片顶部有一个开关：**第三方中转（接口地址与价格都自己填）**。

- **关着（默认）= 官方直连**：接口地址自动填官方域名，价目表自动同步官网价格，你不用管价格。
- **打开 = 第三方中转**：接口地址、中转渠道名称由你填，价格到「AI 用量」页给该渠道的模型逐个填写。

**为什么要分开**：中转站常有**倍率**（1:1、1:5 等），而且一个中转渠道经常同时挂着 GPT、Claude、Gemini 等多家模型。
如果只是"选完官方再手动改个地址"，系统不知道你已经切到中转，仍会按官方价算钱——**不报错，但成本数字是错的**。
打开这个开关就是明确告诉系统"按中转价算"。

配置步骤：

1. 打开「第三方中转」开关
2. 供应商仍选实际使用模型的**那一家**（中转 GPT 就选 ChatGPT / OpenAI）
3. 接口地址填中转商给的地址（一般形如 `https://中转站域名/v1`）
4. 填中转商给的 API Key，填个中转渠道名称方便自己区分
5. 测试连接 → 获取模型 → 选默认模型 → 保存
6. 到「AI 用量」页找到这个渠道（标签会显示「中转」），点模型行的「改价」填写该渠道的**实际单价**

> - 中转渠道只列出你填的模型，不会混入官方目录里这个渠道调不通的模型。
> - 中转渠道不做官网价自动抓取（地址不是官方域名，抓了也抓不到）。
> - 有多个中转站时，逐个配置保存即可，之后在「AI 用量」页按渠道分别管理。

### 3.1b 角色与权限（系统设置 → 角色与权限）

不用写 JSON，全部勾选：

- **角色显示名**：内置五个角色（owner/admin/editor/reviewer/viewer）的中文叫法可以改成贵公司的习惯（例如 admin 改成「运营主管」）。改的是显示名，代码里仍是原角色代码，界面各处自动跟着变。
- **权限表**：左侧是权限项（按「内容生产 / 发布与数据 / 账号绑定 / 系统管理 / 工作区管理」分组），右侧是角色列。**勾选 = 该角色可以做这件事**。
- 高风险权限会标红（删除用户与改角色、删除/永久清除工作区、修改系统设置），建议只给「所有者」。
- 某一权限**全部不勾**表示不限制（所有人都能做）。
- 点「恢复出厂设置」可回到默认权限。

保存后立即生效，用户下次操作就按新权限执行。

### 3.1c 通知渠道（系统设置 → 通知渠道）

开关式，可同时开多个：

- 每个渠道一个开关（群机器人 / 邮件）。**打开哪个开关就展开哪个渠道的配置**，两个可以一起开，互不影响。
- 关掉开关**不会清空已填的地址**，下次打开不用重填。
- 右上角显示「已启用 N 个渠道」，每个渠道旁显示「已就绪」或「待完善」。
- 下方「通知规则」是公共项：推送到群/邮件的最低级别、发布失败是否通知、账号到期提前提醒天数。

### 3.1d 平台密钥（系统设置 → 平台密钥）

同样是开关式，打开才展开该平台的凭据字段：

- 八个平台：微信公众号、视频号、抖音、小红书、知乎、今日头条、百家号、企鹅号
- 打开开关 = 这个平台要接入；下方展开填写凭据（加密存储，界面只显示前后几位）
- 视频号、知乎、今日头条、企鹅号**没有官方发布 API**，不需要填凭据，界面标注「插件发布」
- 平台凭据（AppID/Secret）用于对接与拉数据；**实际账号授权在「账号管理」里做 OAuth 绑定**，两者不是一回事

### 3.2 绑定平台账号（账号管理）

- **微信公众号**：填 AppID/AppSecret 即可（只用于拉取图文数据；平台禁止 API 自动发布，发布走人工）
- **抖音 / 小红书**：需要开放平台 OAuth 令牌，绑定后填 Access Token / Refresh Token
- **视频号 / 知乎 / 头条 / 百家号**：不需要令牌，走浏览器插件半自动填充

### 3.3 平台授权绑定（OAuth，推荐）

账号管理页 → 「平台授权绑定」，选择平台 → 点「去授权」→ 在平台官方页面授权 → 自动跳回并绑定账号。

**前提**：先在「系统设置 → 平台密钥」里填好对应平台的 AppID / AppSecret，否则点「去授权」会提示未配置。

| 平台 | 授权后能做什么 | 备注 |
| --- | --- | --- |
| 微信公众号 | 拉取图文数据（阅读/分享/收藏） | 平台禁止 API 发布，发布仍需人工复制 |
| 抖音 | 官方接口发布视频 | 需要开放平台应用审核通过 |
| 小红书 | 官方接口发布笔记 | 需要开放平台企业资质 |

**平台后台要登记的回调地址**（复制给平台审核用）：

```
https://<你的站点>/api/accounts/oauth/wechat_mp/callback
https://<你的站点>/api/accounts/oauth/douyin/callback
https://<你的站点>/api/accounts/oauth/xiaohongshu/callback
```

授权得到的令牌是**加密后存进数据库**的，界面只显示"已配置/未配置"，不会回显令牌内容；令牌快过期时系统会自动刷新（每 30 分钟检查一次）。

### 3.4 安装浏览器插件（可选，用于插件类平台）

1. 打开 `chrome://extensions` → 打开「开发者模式」
2. 「加载已解压的扩展程序」→ 选择 `apps/plugin/dist` 目录
3. 点插件图标 → 填服务地址（默认 `https://auto.liangyijianye.cn`）→ 用同一个账号登录

## 4. 成员与权限（用户管理）

「用户管理」页（仅管理员/超管可见）：

- **添加成员**：邀请（生成一次性临时密码）或创建；对方首次登录后会被强制要求改密
- **角色**：owner 超级管理员 / admin 管理员 / editor 内容运营 / reviewer 审核人 / viewer 只读
- **重置密码**：生成新的临时密码（只显示一次），对方下次登录需修改
- **停用/启用**、**软删除**（保留审计痕迹，账号立即无法登录）
- 页面顶部「修改密码」可自助改密（≥8 位且含字母+数字）

**防呆保护**（系统会直接拒绝）：不能删除/停用自己、不能取消自己的管理员角色、不能删除或停用最后一个管理员。

## 5. 内容审核工作流

1. 编辑在内容编辑器点「提交审核」（标题/正文不能为空，同一内容不允许重复提交）
2. 审核人（owner/admin/reviewer）在「内容审核」页看到待审条目 → 打开可看内容预览与检查项（合规表述 / AI 标识 / 事实准确性 / 文字差错 / 品牌口吻）
3. 决定：**通过**（内容变「已通过」）/ **要求修改** 或 **驳回**（必须写原因，内容退回草稿）
4. 提交人会收到站内通知；编辑器右栏显示审核记录与驳回意见
5. **不能审核自己提交的内容**（职责分离）
6. 可选门禁：系统设置里开启「发布前必须审核通过」后，只有「已通过」的内容才能创建发布任务

## 6. 日常操作流程

### 6.1 写内容（内容中心 → 新建内容）

- 填标题、摘要、正文、标签；正文可用 AI 生成
- 「内容来源标识」选择是否 AI 参与，默认「人工撰写」。选成 AI 类只会记录标识，**不会往正文里插入任何文案**，也不会因此拦住发布
- 点「保存内容」

### 6.1b 从零写一篇：AI 一键生成（编辑器 → 「AI 一键生成」）

不知道从哪下笔时用它：给一个主题，AI 直接起草一整篇（标题 + 摘要 + 正文 + 标签）。

1. 点「AI 一键生成」，填**主题**（必填，写具体一点效果更好，例如"秋季肠道健康科普，面向 30-50 岁人群，讲清膳食纤维的作用与日常补充方式"）
2. 可选：目标平台（决定语气与长度）、品牌、语气要求、必须覆盖的关键词
3. 点「开始生成」→ 结果**填入编辑器表单**，不会自动保存
4. 生成后左栏会出现「本次生成引用的品牌资料」卡片，列出 AI 依据的资料；**如果显示 0 条，说明知识库里没有这个主题的资料，AI 是自由发挥的**——建议先去知识库补资料再生成
5. 核对事实（成分、规格、数字）后点「保存内容」

两点必须知道：

- **它和「AI 多平台适配」不是一回事**：一键生成是**从零起草**（还没有内容时用）；多平台适配是把你**已经写好**的正文改写成各平台版本（有内容后分发时用）。
- **AI 产物必须人工确认**：一键生成的结果只是**填进表单的草案**，不写进数据库。要不要标注「内容来源标识」完全由您决定——系统默认「人工撰写」，不会自动改成 AI 辅助、不会自动往正文加文案，也不会因为没标就拦发布。
- 按《人工智能生成合成内容标识办法》，是否标注由发布者负责。如果用了 AI 又选择不标，系统会在审计日志留一条记录（`content.ai_flag.reminded`）以便追溯，但**不会替您做决定**。

### 6.2 品牌知识库怎么用（重要）

「品牌知识库」是让 AI 写出"你的话"的关键：

1. **录什么**：品牌定位与话术基调、产品卖点（规格/配方/卖点）、成分说明、合规红线、常见问答
2. **怎么被引用**：AI 做多平台适配时，会拿内容的标题/正文/标签去匹配资料的「标签 + 关键词」，取优先级最高的 5 条拼进提示词
3. **生成前可确认**：编辑器里点「AI 多平台适配」，对话框会显示"本次将引用 N 条品牌资料"，并列出每条的命中原因；如果显示 0 条，说明该主题缺资料，去知识库补标签/关键词即可
4. **优先级**：0-100，越大越优先（合规红线、品牌总纲建议设 10，确保每次都被带上）
5. **被引用次数**：可以判断哪些资料真正有用；**停用**的资料立即不再参与匹配（想留档但停用就选"停用"，不要删）
6. **内置种子**：首次初始化会写入 6 条（卿尔美 3 条、金善加 1 条、长青元 1 条、全品牌合规红线 1 条），可按需修改

### 6.3 用文档批量建资料（上传 PDF / Word / Excel）

「品牌知识库 → 导入文档」：

1. 选文件（PDF / Word / **PPT** / Excel / CSV / txt / md，单个 ≤10MB，**可多选批量上传**），填品牌与分类，选择「生成草稿」或「直接启用」
2. 系统自动解析纯文本、按段落切成若干片（每片约 1200 字、带重叠），**一片 = 一条资料**
3. 弹窗会列出切片标题与摘要，抽查没问题后点「全部启用」；也可以稍后在列表里逐条编辑标签/关键词再启用
4. 原始文件会留档（`uploads/knowledge/`），每条资料带「来源：文件名」标签，可追溯

**图片上的文字也能提取**（本地 OCR，离线、免费、不调用任何 AI 接口）：

- PPT / Word 里的图片、扫描版 PDF（没有文字层）会自动走本地 OCR（tesseract 中文识别）
- 单份文档最多识别 20 张图片（扫描 PDF 最多 10 页），超限会在结果里提示
- OCR 对清晰截图接近满分，对低分辨率扫描件仍可能有少量错字——所以默认落成**草稿**，建议抽查后再启用；错字可以直接在列表里编辑
- 老版 `.ppt` 请在 Office 里另存为 `.pptx`

**批量上传**：可一次选多个文件，逐个解析并逐个显示状态，某个文件失败不影响其它文件。

**先校对、再入库（重点）**：导入对话框是两段式的——

1. 「解析并校对」：只解析、**不写数据库**，按段落切成约 1200 字一片；
2. 复核校对台：文件名标签页 + 逐片文本框，可直接改字、删除整片、合并到上一片、按段落重新拆分，也能一键「还原为原始解析结果」。标有「图片识别，重点核对」的片段来自本地 OCR，请重点看数字、规格、单位；
3. 点「确认无误，录入知识库」才真正入库（可多个文件一起「全部确认入库」）。

入库后横幅会出现「查看『文件名』导入的资料」，点一下就能筛出这批资料。列表里每一条都能继续**编辑 / 停用 / 删除**，来源列显示它来自哪个文件、是否含图片识别内容，随时可以对照原文修正。

注意：如果文档既没有文字层、OCR 也没识别出内容，会明确报错，不会产生垃圾资料。

### 6.4 生成多平台版本（编辑器右栏 → AI 多平台适配）

1. 勾选目标平台（可多选），可填语气与关键词
2. 点「开始生成」→ 右栏「平台版本」出现各平台文案
3. 已存在的平台默认跳过；勾「覆盖已存在的同平台版本」才会重写

### 6.5 合规检查（编辑器 → 合规检查）

按《广告法》与食品宣传要求检查医疗功效、绝对化用语、效果承诺、权威背书四类风险，给出命中词、原因与修改建议，并给出 0-100 分。发文前建议都跑一次。

### 6.6 发布

在编辑器点「创建发布任务」：

- **留空排期时间** = 立即进入发布队列
- **选择未来时间** = 进入排期日历，到点自动入队
- 多选平台可一次创建多个任务

各平台行为：

| 平台 | 行为 |
| --- | --- |
| 微信公众号 | 任务变成「待人工发布」，需复制内容到公众号后台发布 |
| 抖音 / 小红书 | 走官方接口发布（需绑定账号令牌） |
| 视频号 / 知乎 / 头条 / 百家号 | 用插件打开编辑器自动填充，**人工点发布** |

### 6.7 查看与处理（发布队列 / 排期日历）

- **发布队列**：按状态筛选（排期中/待发布/待人工发布/已发布/失败），失败任务可「重试」，失败原因直接显示
- **排期日历**：按周查看，点任务卡片可查看详情或「重试/立即执行」
- 失败会自动重试（默认 3 次、间隔 5 分钟），最终失败会写入右上角**通知铃铛**并模拟发送邮件

### 6.8 看数据（数据中心）

- 顶部四个指标：内容总数、已发布、待处理、发布失败
- 折线图：近 14 天的发布/失败/阅读播放趋势
- 「同步平台数据」：拉取已发布内容的平台数据（需要绑定账号）
- 右侧与下方：账号排行与明细

## 7. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 「AI 服务调用失败：未配置 AI_API_KEY」 | 到系统设置填 Key 并保存，或把提供方切换为离线模板 |
| 发布任务停在「待人工发布」 | 正常现象：公众号禁止 API 发布，需人工复制发布 |
| 抖音/小红书发布失败「未绑定账号」 | 到账号管理绑定账号并填令牌 |
| 任务一直「待发布」 | Worker 未运行：系统设置确认「启用发布 Worker」为开启，或重启 API 服务 |
| 页面打不开 | 检查 nginx 与 `mediaflow-web`/`mediaflow-api` 服务状态（见部署文档） |

## 9. 角色权限

下表是**出厂默认值**，在「系统设置 → 角色与权限」里勾选即可调整，改完立即生效。

| 角色 | 出厂默认权限 |
| --- | --- |
| owner 所有者 | 全部权限 |
| admin 管理员 | 内容、发布、账号、系统设置、用户管理、工作区管理与导出 |
| editor 内容编辑 | 创建/编辑内容、归档、发布、知识库维护 |
| reviewer 审核员 | 审核内容 |
| viewer 只读 | 只读业务数据（系统设置返回 403） |

> 角色显示名可以改（例如 admin 改叫「运营主管」），但角色代码不变。
